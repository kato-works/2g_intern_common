# 油圧とは？

- 油圧は、「油（液体）」の圧力を利用して力を伝えたり増幅したりする仕組みです。
- 液体は圧縮されにくい性質があるため、高い力を効率よく伝えることができます。

## 基本原理

油圧の基本原理は「パスカルの原理」です。パスカルの原理とは、液体や気体のような流体が閉じた容器内に存在する場合に適用される基本的な物理法則で、「流体に加えられた圧力は、容器内のすべての点に等しく、同じ大きさで伝わる」というものです。

この原理を利用すると、図のようにAのおもり1個でBのおもり4個を支える力を発生させることができます。

## 油圧システムの基本構成

油圧システムは以下のような機器により構成されます。

1. ポンプ
   - 油を圧縮して高い圧力を作り出します。エンジンやモーターで駆動します。
2. 油圧配管
   - 油を各部品に運ぶための管やホースです。
3. バルブ
   - 油の流れを制御し、必要な場所に圧力を届けます。
   - オペレータが操作する「コントロールバルブ」があります。
4. アクチュエータ
   - 油の圧力を機械的な力に変換します。
   - シリンダー : 油圧を使って直線的な動きを作る。
   - 油圧モーター : 回転する動力を作る。
5. 油圧タンク
   - 使用後の油を回収し、再利用の準備をします。

## 油圧の特徴とメリット

- 高い力を生み出せる
  - 数トンの荷物を簡単に持ち上げたり動かしたりできる。
- 細かい動きの制御が可能
  - ミリ単位で動作を調整できる。
- 頑丈で信頼性が高い
  - 過酷な環境（雨、泥、粉じんなど）でも動作する。

## 油圧の注意点

- 油漏れや部品の摩耗に注意し、定期的なメンテナンスが必要
- 油圧システム内の高圧油は非常に危険なので、安全対策が重要

## ラフタレーンクレーンにおける油圧システム概要

ラフタレーンクレーンは非常に多くの場所が油圧で稼働する複雑な構造を持っています。

- 巻上装置（ウインチ）
  - ワイヤロープで吊った荷の巻き上げおよび巻き下げを行います。
  - 主巻・補巻のウィンチそれぞれに油圧モーターが設置されており、独立して動作します。
- 旋回
  - 旋回モータおよび旋回ベアリング外側サークルは､上部本体側にあります｡
  - 旋回ベアリング内側サークルは下部本体に固定されています。
  - 旋回モータにとりつけられたピニオン（ギア）が内側サークルのギアとかみ合うことで、上部旋回体が動きます。
- 起伏（ブーム・ジブ）
  - ブーム起伏シリンダ（デリックシリンダ）のヘッド側から作動油が入ると、シリンダは伸びてブームが上がります。
  - 逆にロッド側から作動油が入るとブームは下がります｡
- 伸縮（ブーム・ジブ）
  - ブームは､油圧シリンダ（テレスコピックシリンダ）とワイヤロープで伸縮します｡
  - 複数段に重ねたボックスブームの内部に､2～3本のブーム伸縮シリンダと､ワイヤロープ､伸縮用シーブが取り付けられています｡
  - シリンダのヘッド側から作動油が入るとブームは伸び､ロッド側から作動油が入るとブームは縮みます｡
  - 先端ブームは､すぐ下のブーム(5段ブームなら4段目､4段ブームなら3段目)の伸縮力を利用して､ワイヤロープで伸縮させます｡
- アウトリガー伸縮・上下
  - 各アウトリガーには、伸縮用・上下用のシリンダーが設置されています。
  - 本体側のシリンダのヘッド側から作動油が入ると、シリンダは伸びてアウトリガーが張り出されます。
  - アウトリガー先端に取り付けられた上下動用のシリンダーのヘッド側から作動油が入ると、シリンダは伸びてクレーンを持ち上げます。
