## 建設機械の構成

<image src="sl500rf3.jpg" width="500px">

- フレーム
  - 建設機械のフレームは、動物の骨格にあたります。
  - 骨格がしっかりしているからこそ、重い荷物を持ったり、地面を掘ったりする力を支えることができます。
  - フレームは製缶加工により鉄板を折り曲げ溶接することで、強度を出しています。
- エネルギー・動力
  - ほとんどの建設機械は、ディーゼル燃料を燃やしてエンジンを動力として建設機械は動いています。
  - 加藤製作所ではハイブリッドエンジンを搭載した機種や、200V電源を元にモーターで稼働する機械も発売しています。
  - 今後、環境に配慮した機械の開発が市場から求められています。
- 油圧回路
  - 動力で作られた力は、主に油圧を使って機械全体に伝達されます。
    （走行にはプロペラシャフトが動力伝達に利用されます）
  - 動物でいえば、血液と筋肉にあたるのが油圧系です。
  - 油圧の仕組みについては後述します。
- 制御系
  - 制御系は、ハーネスと呼ばれる電線によって建機全体に張り巡らされておりセンサーとECU（電子制御ユニット）が接続されています、動物でいえば神経・脳にあたります。
  - 建機に設置された多くのセンサーの値を元に、機械の動くスピード・量などを決めるのが制御の担当です。
  - エンジンの回転数、油圧の分配などを制御することによって制御は実施されます。
- インタフェース
  - 建機と人間の間にあるのがインタフェース・操作系です。
  - 機械式と電気制御が存在しており、徐々に電気制御に入れ替わっています。
  - 機械の状態を確認できるモニターが通常は設定されており、オペレータはこの情報を元に作業を行います。

## 油圧について

クレーンをはじめとする重機は、力を油圧を使って伝達することで動作しています。
今回のインターンでは、油圧について触れることがほぼないため、簡単にここで触れておきます。

- 油圧は、「油（液体）」の圧力を利用して力を伝えたり増幅したりする仕組みです。
- 液体は圧縮されにくい性質があるため、高い力を効率よく伝えることができます。

### 基本原理

油圧の基本原理は「パスカルの原理」です。パスカルの原理とは、液体や気体のような流体が閉じた容器内に存在する場合に適用される基本的な物理法則で、「流体に加えられた圧力は、容器内のすべての点に等しく、同じ大きさで伝わる」というものです。

この原理を利用すると、小さな力を大きな力に変換することが出来ます。

<image src="Working_principle_of_a_hydraulic_jack.svg.png" width="500px">

### 油圧システムの基本構成

油圧システムは以下のような機器により構成されます。

1. 油圧ポンプ
   - 油を圧縮して高い圧力を作り出します。エンジンやモーターで駆動します。
2. 油圧配管
   - 油を各部品に運ぶための管やホースです。
3. バルブ
   - 油の流れを制御し、必要な場所に圧力を届けます。
   - オペレータが操作する「コントロールバルブ」があります。
4. アクチュエータ
   - 油の圧力を機械的な力に変換します。
   - シリンダー : 油圧を使って直線的な動きを作る。
   - 油圧モーター : 回転する動力を作る。
5. 油圧タンク
   - 使用後の油を回収し、再利用の準備をします。

### 油圧の特徴とメリット

- 高い力を生み出せる
  - 数トンの荷物を簡単に持ち上げたり動かしたりできる。
- 細かい動きの制御が可能
  - ミリ単位で動作を調整できる。
- 頑丈で信頼性が高い
  - 過酷な環境（雨、泥、粉じんなど）でも動作する。

### 油圧の注意点

- 油漏れや部品の摩耗に注意し、定期的なメンテナンスが必要
- 油圧システム内の高圧油は非常に危険なので、安全対策が重要

### ラフタレーンクレーンにおける油圧システム概要

ラフタレーンクレーンは非常に多くの場所が油圧で稼働する複雑な構造を持っています。

<image src="crane_move.png" width="500px">

- 巻上装置（ウインチ）
  - ワイヤロープで吊った荷の巻き上げおよび巻き下げを行います。
  - 主巻・補巻のウィンチそれぞれに油圧モーターが設置されており、独立して動作します。
- 旋回
  - 旋回モータおよび旋回ベアリング外側サークルは､上部本体側にあります｡
  - 旋回ベアリング内側サークルは下部本体に固定されています。
  - 旋回モータにとりつけられたピニオン（ギア）が内側サークルのギアとかみ合うことで、上部旋回体が動きます。
- 起伏（ブーム・ジブ）
  - ブーム起伏シリンダ（デリックシリンダ）のヘッド側から作動油が入ると、シリンダは伸びてブームが上がります。
  - 逆にロッド側から作動油が入るとブームは下がります｡
- 伸縮（ブーム・ジブ）
  - ブームは､油圧シリンダ（テレスコピックシリンダ）とワイヤロープで伸縮します｡
  - 複数段に重ねたボックスブームの内部に､2～3本のブーム伸縮シリンダと､ワイヤロープ､伸縮用シーブが取り付けられています｡
  - シリンダのヘッド側から作動油が入るとブームは伸び､ロッド側から作動油が入るとブームは縮みます｡
  - 先端ブームは､すぐ下のブーム(5段ブームなら4段目､4段ブームなら3段目)の伸縮力を利用して､ワイヤロープで伸縮させます｡
- アウトリガー伸縮・上下
  - 各アウトリガーには、伸縮用・上下用のシリンダーが設置されています。
  - 本体側のシリンダのヘッド側から作動油が入ると、シリンダは伸びてアウトリガーが張り出されます。
  - アウトリガー先端に取り付けられた上下動用のシリンダーのヘッド側から作動油が入ると、シリンダは伸びてクレーンを持ち上げます。

## 立川事業所で作っているもの

立川事業所は、クレーンの中で電装品と呼ばれる部品の設計・製造を担当しています。

- 上部旋回体
  - 過負荷防止装置（ACS）
    <image src="ACS.png" width="600px">
    - クレーンの各種センサからの入力情報から、クレーンに働くモーメントを演算し、定格性能に近づくと警報を発信、定格性能を超えると危険側への作動（デリック伏せ、ウインチ巻き上げ、テレ伸長）を停止させる。
    - 入力信号
      - デリックシリンダのヘッド側・ロッド側の差圧を検出し、吊荷・吊具・ワイヤロープ・ブームなどの質量を含んだ総合モーメント
      - 角時計から、ブーム角
      - ブーム長さ計から、ブーム長
      - ブーム先端部の巻過検出装置による、フックの巻過状態
      - 旋回角時計から、走行体に対する上部旋回体の旋回角度
      - ジブ長さ、ジブオフセット角度
      - アウトリガの張り出し長さ
      - ブーム作業状態（メインブーム・ルースシーブ・ジブセット・ジブ・ジブ付きメイン）
      - アウトリガ設置状態（アウトリガ使用・定置つり・走行つり）
  - SDロガー・ブラックボックス（K-COR）
    - クレーンの動作状況をSDカード記録する。
    - 事故時に分析を行うほか、Webサイトにアップロードすることで作業報告書を作成することが出来る。
  - テレマ送信機
    - K-CORの後継デバイスとして、位置情報と合わせて直接クラウドへデータをアップロードする。
  - 外部表示灯（三色パトライト）
    - LEDの点灯により、クレーンの運転状況・負荷状況を周囲に伝えることで、安全性を向上させる。
  - 角度・長さ計
    - 振り子の角度によりブームの角度を、引き出されたワイヤー長によりブーム長さを検出し、ACSに伝える。
  - ジブストロークセンサ
    - ジブ長をワイヤーの引き出された長さによって検出し、ACSに伝える。
  - リレーボード
    - ACSと連動して、クレーンの上部旋回体の各動作を制御するリレー群。
  - セーフティービュー
    - クレーンの周囲の３６０度画像を合成して、オペレータの死角を減らす。
  - トップターミナル
    - ブーム先端に取り付けられ、各種センサーの入出力を取りまとめてACSと送受信する。
- 走行体
  - 障害物センサ
    - 超音波センサーにより、走行時のクレーン周辺の障害物を検出して、ドライバーに通知する。
  - 傾斜センサ
    - 車体の傾きを検出してCORに送信することで、サスペンションの調整や、アウトリガーの高さ調整に利用される。
  - リレーボード
    - CORと連動して、クレーンの下部走行体を制御するリレー群
  - アウトリガストロークセンサ
    - アウトリガの張り出し長をワイヤーの引き出された長さによって計測して、ACSに伝える。
